# Suitelifediary
Luxury hotel UGC creator

Website for **Suite Life Diary** ([@suitelifediary](https://www.instagram.com/suitelifediary/)) by Priya, capturing luxury, boutique and one-of-a-kind hotel experiences.

## What's here

- `index.html`: the full website (one page: about, services, stays, moments, testimonials, contact)
- `images/`: all photos used on the site, resized for fast loading

## Publish it as a live website (GitHub Pages)

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Pick the `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute or two the site is live at `https://priya-kumari-17.github.io/suitelifediary/`.
